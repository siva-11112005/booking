## API Endpoints

### Registration/Login
```
POST /send-otp
{
  phone: "+919876543210",
  email: "user@example.com",
  sendVia: "sms"  // or "email"
}
```

### Password Reset
```
POST /forgot-password
{
  email: "user@example.com",
  sendVia: "email"  // or "sms"
}

POST /reset-password
{
  email: "user@example.com",
  otp: "123456",
  newPassword: "newPassword123"
}
```

## User Experience Flow

### Register via SMS (Default)
```
1. User enters phone
2. Click "Send OTP via SMS" (or default)
3. Receives SMS: "Your OTP: 123456"
4. Sees option: "Use Email instead?"
5. Enter OTP
6. Account created ✅
```

### Register via Email
```
1. User enters email
2. Click "Send OTP via Email"
3. Receives email with OTP
4. Sees option: "Use SMS instead?"
5. Enter OTP
6. Account created ✅
```

### Reset Password with Choice
```
1. Click "Forgot Password?"
2. Enter email or phone
3. Choose: "Email" or "SMS"
4. Receive OTP via chosen method
5. Can still switch if needed
6. Enter new password
7. Password reset ✅
```

## How to Update Frontend

When calling the endpoints, pass the new parameters:

### Registration - Now with sendVia
```javascript
// Old (still works as default SMS)
await fetch('/api/auth/send-otp', {
  body: { phone, email }
})

// New (explicit method selection)
await fetch('/api/auth/send-otp', {
  body: { phone, email, sendVia: 'email' } // user choice
})
```

### Password Reset - Now with sendVia
```javascript
// Old (defaulted to email)
await fetch('/api/auth/forgot-password', {
  body: { email, preferEmail: true }
})

// New (user chooses)
await fetch('/api/auth/forgot-password', {
  body: { email, sendVia: 'email' } // or 'sms'
})
```

## Support & Troubleshooting

### "Maximum OTP limit reached"
→ Different limits: SMS 5/day, Email 10/day
→ User can try alternative method
→ Try again tomorrow

### "Please wait 1 minute"
→ Spam prevention
→ OTP already sent
→ Check SMS/Email inbox

### OTP not received
→ Check rate limits
→ Check spam folder
→ Verify phone/email format
→ Try alternative method

### Email not working
→ SMS will be sent as backup
→ Check email credentials in .env
→ Verify Gmail app password

### SMS not working
→ Email will be used as fallback
→ Check SMS Gateway credentials
→ Verify phone format (Indian)
